Project Description

**Problem:**
Students and local communities often face difficulty in discovering nearby events and booking tickets efficiently. Event organizers rely on manual or unorganized systems, which leads to poor crowd management, duplicate entries, and lack of visibility for local events.

**Solution:**
We built a Hyper-Local Event Ticketing Platform that allows users to easily discover nearby events, book tickets online, and gain entry using secure QR codes. Organizers can create and manage events through a dedicated dashboard, ensuring smooth operations and real-time tracking of attendees.

**Key Features:**

* Event discovery and online ticket booking
* QR code-based secure entry verification
* Admin dashboard for event creation and management

**Tech Stack:**
React (Vite), Tailwind CSS, FastAPI (Python), MongoDB Atlas, JWT Authentication, QR Code Generator,razorpay

**Impact:**
This solution simplifies event management and enhances user experience by making event discovery and ticketing seamless. It reduces manual errors, prevents unauthorized entry, and promotes local events, helping communities stay connected and organized.
